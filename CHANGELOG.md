# Changelog

## 0.3.1

- Плагин больше не зависит от стороннего `usage-stats`: токены берутся из встроенного token-meter DSH, а если его нет — напрямую из `session.v4.jsonl.zstd`.
- Добавлен нативный fallback: разбор zstd-логов сессий, заголовок, название чата, проект и сводка токенов за день.
- README (EN / RU / ZH) больше не обещает кеш `usage-stats` и явно говорит, что дополнительный плагин не нужен.

## 0.3.0

- Общий Application ID `1567993796355031070` теперь подставлен по умолчанию: плагин работает сразу после установки.
- Добавлены три языка интерфейса и Rich Presence: русский, английский и китайский. По умолчанию — английский.
- Переключатель `RU / EN / CN` в шапке настроек; выбор сохраняется в конфиге и сразу меняет Activity.
- Китайская локаль `locale/zh.json`.
- README переписан для людей, добавлены три версии (EN / RU / ZH), hero-баннер и настоящий скриншот профиля.
- Иконка плагина обновлена на выбранный вариант с китом DeepSeek.
- Тесты проверяют языки RPC, подсказку на арте и значения по умолчанию.

## 0.2.1

- Исправлен ID активной сессии: клиент присылает `session-<id>.json`, Host нормализует его и находит нужный файл кеша. Раньше название чата и токены чата оставались пустыми.

## 0.2.0

- Показывает название открытой вкладки, а не последнего проекта по времени.
- Добавлены токены текущего чата и подсказка `N токенов за чат` на арте.
- Активная вкладка определяется через заголовок сессии и обновляется при переключении.
- Читаются только файлы кеша, изменённые сегодня: меньше работы на каждом тике.
- Поиск Discord IPC для Windows, Linux, macOS, Flatpak и Snap; путь можно переопределить через `DSH_DISCORD_IPC`.
- Настройки: иконка и подсказка вынесены в отдельный блок.
- Добавлены README, лицензия и проверка `npm test`.
